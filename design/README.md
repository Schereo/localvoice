# LocalVoice Brand Assets

[Editable source in Figma](https://www.figma.com/design/2uf6IZr1ERLTdDPyIbPP18/LocalVoice-Logo-Study) · [Logo](https://www.figma.com/design/2uf6IZr1ERLTdDPyIbPP18/LocalVoice-Logo-Study?node-id=1-2) · [macOS app icons](https://www.figma.com/design/2uf6IZr1ERLTdDPyIbPP18/LocalVoice-Logo-Study?node-id=3-2)

The checked-in SVGs reproduce the approved design. The editable `.fig` document is hosted in Figma.

| Asset | Use |
| --- | --- |
| `wordmark-{light,dark}.svg` | Three audio bars and the LocalVoice wordmark in outlined Glory Bold. The website uses a copy of the light SVG as a mask, colored by the active theme. |
| `audio-mark-{light,dark}.svg` | Standalone, transparent audio mark. |
| `app-icon-{light,dark}.svg` | Square, unmasked 1024 px app artwork. |
| `app-icon-{light,dark}-foreground.svg` | Transparent 1024 px layers for Apple Icon Composer. Set the background to `#C8CCBD` (light) or `#2D342D` (dark) and let macOS mask the corners. |

The current installer and dev/release builds still use a single `.icns` template generated by `src/ctrlspeak-icon.swift`. That path uses the light artwork with a rounded plate and transparent outer margin. `assets/icon.png` and `site/assets/icon.png` are raster copies for the README, previews, favicon, and social metadata. The menu-bar image is a monochrome template drawn in `src/ctrlspeak-launcher.swift`.

The wordmark uses [Glory](https://github.com/google/fonts/tree/main/ofl/glory), licensed under the SIL Open Font License 1.1; see `Glory-OFL.txt`.
